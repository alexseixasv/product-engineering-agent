# CE ADR Author

## Instructions

1. Read `docs/adr/INDEX.md` for the next number.
2. Copy structure from `docs/adr/TEMPLATE.md`.
3. Fill Status, Date, Decider(s), Area, Context, Decision, Consequences.
4. Always include **Alternatives rejected** and **Files touched**.
5. Add Related PDRs/ADRs.
6. Update `docs/adr/INDEX.md` in the same change.
7. To reverse a decision: create a new ADR that supersedes; set old Status to `Superseded by ADR-XXX`.
8. Language: English.
